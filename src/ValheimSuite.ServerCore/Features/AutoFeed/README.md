# AutoFeed

Planned first ServerCore gameplay feature.

Do not implement from remembered Valheim behavior. Before coding, inspect the current game and document:

- hunger state
- accepted-food validation
- tameable/AI feeding behavior
- container inventory mutation
- ZNet/ZDO ownership
- dedicated-server simulation behavior
- concurrency around consuming the final item

Use `docs/features/TEMPLATE.md` to create the full feature design first.
